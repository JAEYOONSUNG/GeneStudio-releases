# Gene Studio — releases

Builds of **Gene Studio**, a browser-based plasmid workbench by Jae-Yoon Sung.

This repository holds **only the released files and the version feed**. The
source is not here and is not public: Gene Studio is given to named people for
research, and copying, changing or redistributing it needs written permission.
The terms ship with the application in `LICENSE`.

* `feed.json` — what the application reads to tell you a newer build exists.
* Releases — the installers themselves.
